# archive/ — the pre-online originals

These are the app as it was before it moved online: a double-click-and-open HTML
file with all its data in one browser's `localStorage`. Kept for reference and
as a fallback while the online version beds in.

- `schads-timesheet-calculator_36.html` — the standalone app. Still works
  offline, still holds whatever data you last had in it. **This is where your
  existing data lives until you export it** — see "Moving your existing data
  across" in the main README.
- `schads-timesheet-calculator_6.jsx` — the React source it was built from.

**Don't edit either of these.** The live app is `../index.html`, and the source
in it has since diverged. Nothing here is served or deployed.
